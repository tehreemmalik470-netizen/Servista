# 🌌 Servista - Premium Decentralized Service Workspace

Servista is a modern MERN-stack web application designed to bridge the gap between premium service providers and clients through a streamlined, secure, and intuitive digital ecosystem.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, React Router DOM
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JSON Web Tokens (JWT) & Google OAuth 2.0 Integration

---

## 🌟 Core Features

- **Role-Based Protected Routing:** Dedicated execution dashboards for **Admin**, **Providers**, and **Clients**.
- **Secure Authentication:** Traditional secure password hashing combined with a seamless "Continue with Google" social login pipeline.
- **Premium Dark UI Theme:** Modern, high-fidelity responsive user interface featuring dynamic SVG tech-mesh overlays.
- **Service Management Panel:** Live operational base tracking (e.g., Sialkot region tracking) and service specialty metrics.
